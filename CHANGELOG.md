# Changelog
Все значимые изменения в этом пакете будут задокументированы в данном файле.

## [1.0.4] - 2026-07-03
### Changed
- Отключено предупреждение throw о не добавленном конечном кондишине,
на данный момент при создании группы без конечного кондишина, группа закрывается только при закрытии всех шагов.

### Added
- Добавлено визуальное отображение типа и стартовой инструкции элементов ConditionBase в структурах и массивах 
в компонентах StepBase, GroupSteps и в ConditionOrder.
- Добавлена возможность генеративного экспорта статистики по пути Environment.GetFolderPath(Environment.SpecialFolder.Desktop)
во время Start() при условии, что отключена переменная IsCustomPath,
при включённой переменной используется кастомный путь экспорта.
- Добавлен публичный метод SetPathToExport в LogExport для замены пути при необходимости.
- Добавлена механика проверки последовательности выполнения шагов внутри группы шагов.
В группе переменная IsStepsOrderRequired включает проверку последовательности шагов.
В шаге переменная IsStepOrderRequired включает проверку текущего шага в последовательности.
При совершении ошибки выбрасывается классический мистейк.
- Добавлена возможность вызвать ошибку из внешней логики, метод вызывается в ScenarioSystem -> Mistake.
Необходимо отправить кондишн в котором будут данные ошибки и булевую переменную о необходимости завершения сценария.
- Добавлена обработка ошибки последовательности на уровне модуля ошибок через систему Mistake System Awaitable.

### Fixed
- Исправлен null при взаимодействии с PermanentCondition == null.
- Исправлен баг при котором ошибка последовательности в логах считалась успешным выполнением.
- Исправлен баг в экзамене не засчитывались ошибки в некоторых ситуациях.
- Исправлен баг пропуска группы шагов, если в группе нет конечного кондишина, она вторая и их всего 2.
- Исправлен баг сохранения в лог пропущенных кондишинов/шагов/групп.
- Исправлен баг инициализации Universal Event Provider, для выключенных объектов.
- Исправлен баг ошибка последовательности в модуле ошибок прилетала в виде коммон ошибки.

## [1.0.3] - 2026-06-25
### Changed
- Исключёна жёсткая завязка на HVR_InteractiveHelper от HurricaneVR,
добавлен универсальный провайдер GrabProviderBase для взаимодействиями с объектами через HVR_InteractiveHelper.
- Из пакета удалены зависимости на UltraLeap, Rigging, FinalIK, MiniExcelLibs.
- В пакет добавлена зависимость UnityEngine.InputSystem.
- Вынесен функционал горячих клавиш из ScenarioSystem, в новый класс ScenarioSystemHotKeys.
- В классе ScenarioSystemHotKeys реализован ввод для новой и старой систем ввода, 
для работы новой системы необходимо добавить Keyboard (InputActionAsset) в схему инпутов.

### Fixed
- Исправлена критическая проблема цикла тренировки и экзамена.
- Исправлена критическая проблема запуска групп шагов в режимах тренировки и экзамена.
- Исправлена видимость переменных в StepBase(IsInitTypeOverrideSimultaneously, IsConditionOrderRequired)
для настройки тренировки/экзамена при выборе переопределения.
### Deprecated
- Классы EventsHelperBase, EventsHelper, EventsHelperCartController и enum EventParameterType помечены как устаревшие,
будут удалены в версии 1.1.0.
- Класс HvrGrabbableProvider будет вынесен в отдельный пакет для HurricaneVR в версии 1.2.0 и удалён из текущего пакета.
